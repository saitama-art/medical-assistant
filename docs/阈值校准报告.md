## 3. 分离性判断：**不可分**

- 无关类最小值（0.286，二甲双胍价格）**小于**相关类中位数（0.322），
  且落在相关类范围之内（0.244~0.378）内 5/8 处；
- 「感冒 / 胸痛就医 / 股票」等医学近缘但库内无答案的问题（0.45~0.48）
  与「腹泻补水」等真正覆盖的问题（0.378）之间也不存在干净分界；
- 原因：知识库扩编后，说明书与 MSD 科普文档**主题密集**——价格类问题仍命中
  正确的说明书（只是文档里没有价格），top1 距离天然偏低。这与设计 5.4 第 3 步
  「不可比 → 必须重新校准」及第 5.5 节「只靠距离阈值无法解决③类灰区问题」的
  结论一致，且扩编后重叠比盘点时更严重（盘点库只有 11 份说明书、主题稀疏）。

**因此：top1 距离上不存在能把两类分开的阈值。** 任何 ≤0.38 的阈值都会放行
价格类问题；任何 ≥0.29 的阈值都会误杀相关类问题。

## 4. 所选阈值与依据

**`EVIDENCE_THRESHOLD` 维持 `None`（第 1 段保持禁用）。**

依据：

1. 校准数据证明 top1 距离在第 1 段语义下（≤阈值即判证据通过）**无分离能力**，
   启用只会引入双向误判（放行价格类 / 误杀腹泻类）；
2. 第 3 段 LLM 判定 + 第 2 段逐字校验已承担证据判定职责，且真实验收
   T-02b（价格/医保/开封失效三题均 insufficient_evidence）证明其可靠；
3. 设计 5.4 明确：「只有报告完成后，才把数值填入」——本次报告完成的结论
   就是"不填数值"，不是未校准状态的延续；
4. 度量已实证为 L2 平方。若未来知识库/embedding 变更使两类重新可分，
   重跑 `scripts/calibrate_threshold.py` 即可再校准。
