# FR-01 引用支持率人工核验记录（模板）

- 官方验收口径：人工核对，引用支持率 **≥ 0.85**（设计 T-16 / 产品需求 FR-01）。
- 自动指标（T-16-lite，8-gram 字符重合）**仅诊断用**，不构成达标证据。
- 本文件是**待人工填写**的记录模板：预填数据来自
  `backend/acceptance_results/fr01_fix2_20261020.json`（2026-10-20，索引 1041 chunks）。
  正式核验时可重跑 `python -m acceptance --only T-13 --fr01 --out <新文件>` 取新数据，
  分母/判定方法不变。

## 一、统计口径

1. **核验样本**：FR-01 诊断样本 8 条（下表）。均为 outcome=completed 的知识问答。
2. **分母**：每条答案按语义拆分为若干**可判定医学陈述句**（官方 T-16 口径为
   "回答中需要引用支撑的句子"；下表预填的 `自动句数` 来自 T-16-lite 机械切句，
   人工可按语义合并/拆分，调整时在"人工句数"列填写实际采用的分母）。
3. **引用有效**：该句的每一个医学事实/建议都能在下表【参考来源】对应的检索片段
   （top-k 正文）中找到依据。**允许换述**，不要求逐字相同；但来源与结论不一致、
   来源不含该信息、来源编号对不上，均记**不支持**。
4. **引用缺失/错误/来源与结论不一致**：一律记不支持，并在备注写明样本句。
5. **支持率计算**：
   `支持率 = Σ(各样本被支持句数) / Σ(各样本句数)`，全部 8 条合计判定，
   目标 **≥ 0.85**。
6. **不合格样本处理**：支持率 < 0.85 时，逐条登记不合格样本（样本号 + 原句 +
   缺失依据），转修复后重跑本核验，直至达标或产品评审接受现状。

## 二、判定操作步骤（供人工执行）

1. 对每条样本，先读【回答全文】，按语义拆句；
2. 逐句在【参考来源】文档中找依据（需要片段正文时，在 `backend/` 下运行：
   ```powershell
   conda activate ai_agent
   python -c "from app.rag import service as s; r=s.retrieve_with_scores('<问题>'); [print(c.document, c.content[:500], '\n---') for c in (r.chunks or [])[:10]]"
   ```
   注意把问题写成 UTF-8 文件传入，避免 Windows 控制台中文乱码）；
3. 在表尾"人工判定"栏填：该样本被支持句数 / 总句数；有争议句写备注；
4. 8 条填完后按上式计算合计支持率，填写结论与签字（日期）。
