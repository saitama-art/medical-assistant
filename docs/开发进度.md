- 设计取舍（记录在代码注释中，此处摘要）：
  - `safety.py` 的第三人称主体表刻意不收裸的「他/她」——「阿托伐他汀」含「他」，会把药品说明书类问题误判为紧急；这类说法由 `HELP_SEEKING`（「怎么办」「要不要去医院」等）兜住，不会漏拦。
  - 否定判定按词逐个进行，而非整句判断，否则「我没有胸痛但现在突然喘不上气」会被整句否定掉，漏掉真实急症。
