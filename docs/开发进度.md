- 前端只调用主 Agent 链路，安全/路由/证据判定/固定文案在产品路径上真实生效。
- 知识问答能产出「正文 + 来源 + 免责声明」；无证据时明确拒答。
- 紧急、寒暄路径不触发检索与生成。
- 单次请求能走完一条完整业务链路，且后端单测保持全绿。
