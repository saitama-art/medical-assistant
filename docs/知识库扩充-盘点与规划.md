## 三、实施方案（对生产链路零改动）

1. 原始抓取内容存 `kb_src/`（html/txt，逐字保留），**与 `backend/data/` 分离**。
2. 用 fpdf2（本轮新装，仅离线工具使用，不入生产依赖路径）把逐字文本转成 PDF 放入 `backend/data/`——ingest 流程、切分参数、检索逻辑**零改动**。
3. 每份生成 PDF 首页附来源信息块：标题、来源 URL、来源类型、获取日期——来源可追溯且随 chunk 入库。
4. 工具脚本放 `tools/kb_build/`（抓取→转换），可重复执行。
5. 全部入库后统一 `python -m app.rag.ingest` 重建索引，执行第八节质量验收与 87 项单测回归。
6. **不提交 Git**，保留审查。
