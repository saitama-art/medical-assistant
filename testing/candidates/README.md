# 外部测试候选数据

本目录只放**尚未完成项目终审的外部候选样本**。候选数据不计入稳定覆盖率、含草稿设计覆盖率、执行覆盖率或通过率。

## 当前资产

| 目录 | 数量 | 来源 | 状态 |
|---|---:|---|---|
| `healthbench/` | 16 条中文候选（单轮/多轮各 8 条） | OpenAI HealthBench | 待项目路由与医学安全审核 |

HealthBench 候选保留原始 `prompt_id`、对话和医生评分标准，便于追溯。原始评分标准不是本项目的断言：
使用前应重新标注 `expected_route`、风险、禁止结果和知识库证据要求。日文假名和英文主导样本已在本次筛选中剔除。

## 使用纪律

1. 先核对许可证并保留版权与许可文本；HealthBench 的 MIT 声明见同目录 `LICENSE`。
2. 不将原始医生回答或其他模型回答直接当作本项目的标准答案。
3. 不导入真实患者隐私、密钥或来源不明数据。
4. 候选转正式数据集时必须重新编号、记录来源、更新版本并经过人工终审。
5. CBLUE、IMCS-21 等数据在许可未确认前不纳入本目录正式派生数据。
