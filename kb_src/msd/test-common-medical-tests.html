    常见的医疗检查

    完整评审: 2月 2025 作者：The Manual's Editorial Staff | 同行评审人Sandy J. Falk, MD
    上次更新: 2月 2025

    广泛使用的医疗检查有许多种。许多检查可用于特定疾病或一组相关疾病。另一些检查通常用于范围较广的疾病。

    出于各种原因的检查，包括

    • 筛查

    • 诊断一种疾病

    • 评估疾病的严重性以制定治疗方案

    • 监测治疗的反应

    有时一种检查有多个目的。血检可能会显示一个人的血红细胞太少（贫血）。为了确定血红细胞是否回到正常值，在治疗后同样的检查可能还要再次进行。有时，在对一种疾病进行治疗的同时，还需进行筛查或诊断检查。例如，当结肠镜检查（用挠性观察导管检查大肠内部）监测出生长（息肉）时，可以在结肠镜检查完成之前除去息肉。

    一些诊断程序

    一些诊断程序

    程序

    检查的身体部位或样本

    描述

    羊膜腔穿刺术

    包围在胎儿周围的囊中的液体

    用针穿过腹壁得到液体，进行分析，监测胎儿的异常情况

    动脉造影（血管造影）

    身体的任何部位的动脉，通常为脑、心脏、肾、主动脉或腿部的动脉

    通过一根薄管（导管）使用造影剂注入进行 X 线检查，导管被通入要检查的动脉，监测、勾勒或突出动脉中的堵塞

    听力测定

    耳

    用耳机评估听力，以及区分特定音色的声音和音量的能力

    听诊

    心

    用听诊器听心脏声音的异常

    钡餐 X光

    食管、胃、肠或直肠

    X光监测溃疡、肿瘤或其它异常

    活检

    身体的任何组织

    提取组织样本，并在显微镜下研究，检查是否存在癌症或其它异常

    血压测量

    通常为手臂

    通常使用充气臂带缠绕手臂，测量血压的高低

    血液化验

    通常采集手臂的血液样本

    测量血液中的物质，评估器官功能，帮助诊断和监测各种疾病

    骨髓穿刺

    髋骨或胸骨

    通过针提取骨髓样本，使用显微镜检查血液细胞的异常

    支气管镜

    肺气道

    使用观察管直接检查肿瘤或其它异常

    心导管检查

    心

    将导管插入血管并穿入心脏，研究心脏功能和结构

    绒膜绒毛取样

    胎盘

    提取样本在显微镜下研究，检查胎儿的异常

    染色体分析

    血

    在显微镜下研究，监测遗传疾病或确定胎儿性别

    结肠镜检查

    大肠

    使用观察管直接检查肿瘤或其它异常

    阴道镜

    宫颈

    使用放大透镜，直接检查

    计算机断层扫描 (CT)

    身体的任何部位

    用计算机增强X光研究检查结构异常

    锥切活组织检查

    宫颈

    锥形组织提取和检查，通常使用加热线圈或激光

    培养

    身体任何部位的样本（通常为液体，如血液或尿液）

    检查样本微生物的生长，确定细菌或真菌的感染

    扩张和刮宫术（D和C）

    子宫颈和子宫

    使用一个小而锋利的器械（刮刀）刮取子宫内膜，在显微镜下检查样本，以检查异常

    双能X光吸收计量法（DEXA）

    骨骼，集中于具体部位，通产为髋部、脊椎和腕部

    低剂量X光扫描，确定骨密度

    超声心动图

    心

    使用声波研究心脏的结构和功能

    心电图 (ECG)

    心

    使用电极接触手臂、腿和胸，研究心脏的电活动

    脑电图（EEG）

    脑

    使用电极接触头皮，研究脑的电活动

    肌电图

    肌肉

    使用小针刺入肌肉，记录肌肉的电活动

    电生理学检查

    心

    将导管插入血管，并通入心脏，检查心脏节奏或电传导异常

    内镜逆行胰胆管造影（ERCP）

    胆道

    注射染料后使用柔性观察导管，对胆道进行 X 线检查

    内镜检查

    消化道

    使用挠性观察导管直接检查内部结构

    酶联免疫吸附试验（ELISA）

    通常为血液

    检查包括将血液样本与能够触发过敏的物质（过敏原）混合或与微生物混合，检查具体抗体的存在

    荧光透视

    消化道、心脏或肺

    持续的X光检查可以让医生看到活动的器官的内部

    子宫镜检查

    子宫

    使用挠性观察导管直接检查子宫内部

    静脉尿路造影

    肾和泌尿道

    将染料注入静脉（静脉注射），对肾和泌尿道进行 X 线检查

    关节抽吸术

    关节，尤其是肩部、肘部、手指、髋、膝、踝和脚趾

    抽取关节空隙内的液体进行研究，检查血液细胞、矿物质结晶和微生物

    腹腔镜检查

    腹部

    使用观察管直接检查，将观察管通入腹部的切口，诊断和治疗腹部异常

    磁共振成像 (MRI)

    身体的任何部位

    使用强磁场和无线电波造影检查，检查结构性异常

    乳房 X 线摄影

    乳房

    X光检查乳腺癌

    纵隔镜检查

    胸

    将观察管插入胸骨上部的小切口，直接检查肺之间的胸部区域

    脊髓造影

    脊柱

    注射染料后，对脊柱进行单纯或计算机增强 X 线检查

    神经传导检查

    神经

    将电极或针沿神经通道插入，确定神经脉冲波的速度

    隐血检测

    大肠

    监测大便中的血液

    检眼镜检查

    眼睛

    使用可将光照射到眼睛的手持设备，直接研究，监测眼内的异常

    早期子宫颈癌涂片（Pap）检查

    宫颈

    在显微镜下研究子宫颈的刮片细胞，进行癌症监测

    穿刺

    腹部

    将针插入腹腔，提取液体并研究

    经皮肝胆管造影

    肝和胆管

    将染料注射入肝，对肝和胆管进行 X 线检查

    正电子发射断层扫描 (PET)

    脑和心脏

    使用释放辐射的粒子（正电子）造影，监测功能异常

    肺功能检查

    肺

    当测试人群向检测仪器吹气时，检查肺屏气、吸入气体和运出气体，以及氧气和二氧化碳的交换能力

    放射性核素成像

    许多器官

    使用释放辐射的粒子（放射性核素）造影，监测血流、结构或功能的异常

    反射检查

    腱

    通过人体刺激（如轻拍）监测神经功能异常

    逆行尿路造影

    膀胱和输尿管

    将染料注入输尿管，对膀胱和输尿管进行 X 线检查

    乙状结肠镜检查

    结肠、大肠的末端

    使用观察管直接研究，监测肿瘤或其它异常

    皮肤过敏检查

    通常为手臂或背部

    将包含可能过敏原的溶液涂于皮肤上，然后用针刺皮肤并观察反应，以检查过敏

    脊椎抽液（腰椎穿刺）

    脊柱

    将针插入两块椎骨之间的空间，提取脊髓液体，检查脊髓液异常

    肺活量测定

    肺

    肺功能检查包括向测量设备吹气

    应力测试

    心

    使用踏车或其他运动器械以及心电图，检查费力时的心脏功能（如果测试人群不能运动，可使用一种药物模拟运动的影响）

    胸腔穿刺

    覆盖肺和胸壁内膜的两层隔膜——胸膜之间的空隙（胸膜腔）

    用针提取该腔内的液体，监测异常

    胸腔镜检查

    肺

    通过观察管，研究肺表面、胸膜和胸膜腔

    鼓室

    耳

    将仪器伸入耳，测量中耳的耐压性（阻抗），并使用声波，确定听力损失的原因

    超声检查

    身体的任何部位

    使用声波成像监测结构或功能异常

    尿液分析

    肾和泌尿道

    对尿样进行化学分析，监测蛋白质、糖、酮和血细胞

    静脉造影

    静脉

    使用染料进行 X 线检查（类似于动脉造影），检测静脉堵塞

    检查的种类

    检查通常为以下六中类型之一。

    体液分析

    最常分析的体液为

    • 血

    • 尿

    • 脊髓和大脑周围的液体（脑脊髓液）

    • 关节液（滑液）

    实验室检测
    全套代谢功能检测组合 (CMP)

    不常分析汗液、唾液和消化道的液体（例如胃液）。有时只有出现疾病的时候，分析的液体才会出现，因为液体聚集在腹部，导致腹水，或液体聚集在覆盖肺和胸壁内膜（胸膜）的两层隔膜之间的空间内，导致胸腔积液。

    影像

    影像学检查提供身体（整体或部分）内部的图像。影像学帮助医生诊断疾病、确定病情严重程度和疾病诊断后监测病人。绝大多数影像学检查具有无痛、相对安全和非创伤特点（即并不需要切开皮肤或将设备插入体内）。

    影像学检查可能使用：

    • 放射学检查 [如 X 线、血管造影、计算机断层扫描 (CT)]和放射性核素扫描 [包括正电子发射断层扫描 (PET)]

    • 声波，如超声

    • 磁场，如磁共振成像（MRI）

    • 吞咽、注射或插入，以突出显示或勾勒出要检查的组织或器官的物质（称为造影剂）

    在医学成像中使用放射线存在一些风险。

    有关特定诊断和筛查中常用的影像学检查的信息，请参阅以下：

    • 心脏和血管疾病

    • 肺部疾病

    • 肌肉骨骼疾病

    • 脑、脊髓及神经障碍

    • 消化道功能障碍

    • 肝脏及胆囊疾病

    • 尿道疾患

    • 眼疾

    • 妇科疾病

    • 孕期保健：超声

    • 乳房 X 线摄影

    内镜检查

    使用显像管（内镜）直接观察人体器官内部或身体间隙（腔）。最常见的是使用挠性内镜，但是在某些情况下，硬式内镜更有用。内镜的末端通常装有灯和相机，医生可以通过电视监控器观察影像，而不是直接通过内镜观察。内镜管道中有医疗器械穿过。其中一种类型的工具是用来切割和移除组织样本的。

    内镜通常通过人体的一个开窍部位穿入观察管，例如：

    • 鼻：检查喉（喉镜检查）或肺（支气管镜检查）

    • 口：检查食管（食管镜检查）、胃（胃镜检查法）和小肠（上消化道镜）

    • 肛门：检查大肠、直肠和肛门（结肠镜检查）

    • 尿道：检查膀胱（膀胱镜检查）

    • 阴道：检查子宫（子宫镜检查）

    然而，有时需要创造人体的开窍部位。将皮肤或者皮肤下的组织层切一个小口（切口），可以将内镜通入人体体腔。使用这样的切口用来观察如下部位的内部：

    • 关节（关节镜检查）

    • 腹腔（腹腔镜检查）

    • 胸部肺之间的部位（纵隔镜检查术）

    • 肺和胸膜（胸腔镜检查）

    身体功能检查

    通常，身体功能可以通过记录和分析身体各个器官的活动来测量。例如，心脏电活动可以通过心电图 (ECG) 来测量，脑电活动可以通过脑电图 (EEG) 来测量。肺屏气、吸入和呼入气体，以及交换氧气和二氧化碳的能力，可以通过肺功能检查来测量。

    活检

    活检是从人体中取出组织样本进行检查的程序。在显微镜下检查细胞后即可作出诊断。研究常集中于找到可以为炎症或疾病，如癌症提供证据的异常细胞。常被研究的组织包括皮肤、乳房、肺、肝、肾和骨。

    遗传物质分析（基因检测）

    另见遗传学。

    基因诊断技术是用于理解和评估染色体、基因（包括DNA [脱氧核糖核酸]）或这两者的科学方法。通常分析来自皮肤、血液或骨髓的细胞。基因检测用于如下情况的人群：

    • 胎儿：确定他们是否存在遗传疾病

    • 儿童和青年人：确定他们是否患病或有患病的风险

    • 成人：有时为了确定其亲属，如孩子或孙子将患某种疾病的可能性

    基因技术迅速发展。可使用不同方法拷贝基因片段或寻找基因的变化。

    风险和结果

    每项检查都存在某种风险。风险可能是检查中存在身体损伤的可能，或如果结果异常时，可能需要进一步的检查。进一步的检查通常更加昂贵、危险，或者二者皆有。医生会权衡检查提供信息的有用性与其同时存在的风险。

    正常的实验室检查值用一个范围来表示，这个范围基于健康人群的平均值。即，95%健康人群的检测值都在这一范围。但是，女性和男性的平均值可能略有差异，且随着年纪而变化。对于一些检查而言，不同实验室的值也有差异。因此，当医生得到实验室的检查结果时，该实验室也给医生一份他们实验室自己的检查正常值范围。患者应咨询医生其检测结果的意义。
